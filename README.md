# Simple To-Do Website

A small, beginner-friendly to-do list website built with HTML, CSS, and JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Save tasks in browser local storage
- Responsive layout for mobile and desktop

## How to Run
1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No installation or build step is required.

## Technologies
- HTML
- CSS
- JavaScript
- Browser Local Storage
